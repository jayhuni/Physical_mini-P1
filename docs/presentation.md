## 데이터 특이 사항 (근거 수치)

1. **A-CAM1 11/20은 불량 급증이 아니라 장비 이상**
   - D99 11건이 전부 이날 A-CAM1에서 발생. 처리 시간 5000ms, 신뢰도 0 (PORTFOLIO)
   - O2 탐지: 11건, 다른 날 0건(평소 0건) → 자동으로 잡힘 (시설·카메라 단위 모두)
   - D99를 빼면 전체 불량 238 → 227건, 불량률 4.58% → 4.37%. A시설은 여전히 1위
2. **C시설 11/19 치수 초과 21건, 두 카메라 모두 상승** → 카메라보다 공정 원인 의심
   - O2 탐지: 시설 단위 21건, 기대 3.74건, 5.6배 (p = 5.9e-10). 카메라 단위는 C-CAM1(11건, 7.3배)만 기준 통과
   - C-CAM2는 10건, 4.5배였지만 p = 1.1e-4로 기준(0.0001)을 근소하게 넘어 카메라 단위에서는 빠짐 → 시설 단위가 메워 줌 (질문 대비)
3. **B시설 11/18 이물 15건 (5일 이물 27건의 절반 이상)** → 그날 작업 환경·자재 확인
   - O2 탐지: 15건, 기대 3.01건, 5.0배 (p = 6.9e-7)
4. **불량 위치 분포 (O1)**: 박스 227건의 중심이 모두 사진 가운데(x 381~940, y 279~750)에 있다. 4×4 격자에서는 가운데 4칸에 전부 들어가고, 최다 칸은 x 640~960 · y 256~512(66건, 29.1%)
   - 8×8로 보면 가운데에 고르게 퍼져 있어 특정 위치 편중은 없다 → 제품이 사진 중앙에 놓이고 불량은 제품 어디서나 생김. 위치로 원인을 좁힐 근거는 없다는 것도 결론
   - 평균 면적 최대 얼룩 14,949px², 최소 스크래치 11,329px² (사진의 약 1%로 종류 간 차이 작음)
   - 잘못된 박스 좌표 0건 → 좌표 품질 문제 없음
5. O2가 잡은 것은 위 3건뿐(시설·카메라 단위 6행). 무작위 데이터 시뮬레이션으로 정한 기준이 실제 데이터에서도 오탐 없이 동작
