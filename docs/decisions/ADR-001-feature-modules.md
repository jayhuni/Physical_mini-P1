# ADR-001 새 분석 기능은 별도 모듈에 둔다

- 날짜: 2026-11-23
- 상태: 제안 (팀 합의 필요)

## 배경
선택 요구사항 O1(박스 분석)과 O2(급증 탐지)를 두 사람이 동시에 개발한다. TEAM_README 규칙 1은 "집계 코드는 `aggregator.py`에만 둔다"인데, 두 기능을 모두 `aggregator.py`에 넣으면 같은 파일의 끝부분을 동시에 고치게 되어 PR마다 충돌이 난다.

규칙 1의 목적은 **`app.py`(화면)에 집계 코드를 두지 않아 CSV와 대시보드 숫자를 일치시키는 것**이다(명세 D7). 집계가 어느 모듈 파일에 있는지는 목적과 무관하다.

## 결정
- 새 분석 기능은 기능별 모듈 파일에 둔다. 예: O2 → `spike.py`, O1 → `box.py`
- 새 모듈은 `aggregator`의 상수(`DEFECT_RESULT` 등)를 가져다 써서 불량 정의를 한 곳에 유지한다
- `app.py`에 집계 코드를 두지 않는다는 규칙과 테스트(`test_d7_app_has_no_aggregation_code`)는 그대로 유지한다
- `main.py`, `app.py`, `config.py`에는 호출과 설정 몇 줄만 추가한다

## 결과
- 두 기능 PR이 겹치는 곳은 `main.py`·`app.py`·`config.py`의 몇 줄로 줄어든다
- 명세 S1("기능을 함수로 나누고 실행 파일과 별도 모듈에 둔다")에도 맞는다
- TEAM_README 규칙 1의 문구를 "집계 코드는 `aggregator.py`와 분석 모듈에 둔다"로 고쳤다
